MERKAZ — المعرفة في مكان واحد | V1
==================================

التشغيل المحلي:
1) ثبّت Node.js إصدار 20 أو أحدث.
2) افتح الطرفية داخل مجلد MERKAZ.
3) نفّذ: npm install
4) نفّذ: npm run dev
5) افتح الرابط الذي يظهر لك.

البناء قبل النشر:
- npm run build
- مجلد dist الناتج ينشأ تلقائيًا وقت البناء. لا ترفع dist إلى GitHub عادةً.
- في Vercel: Framework Preset = Vite، Build Command = npm run build، Output Directory = dist.

إضافة ملفات TXT:
- ضع أي ملف .txt جديد بجانب ملفات المشروع في نفس المجلد الرئيسي.
- انسخ MERKAZ-TEMPLATE.txt واملأ بيانات الملف والقوانين.
- احفظ ثم نفّذ npm run build أو أعد نشر المشروع على Vercel.
- أثناء البناء يقرأ محرك MERKAZ كل ملفات TXT في المجلد الرئيسي. الملف غير الصحيح يتم تجاهله مع إظهار اسم الملف وسبب الخطأ في سجل البناء، ولا يمنع بقية الملفات من التحميل.

تنسيق TXT:
[MERKAZ]
version=1
title=...
system=azhar | general | baccalaureate
grade=...
track=...
year=...
language=ar

[LAW]
id=unique-id
subject=physics
category=mechanics
title=...
equation=$v = d/t$
explanation<<
نص متعدد الأسطر
>>
symbols<<
v | السرعة | m/s
d | المسافة | m
>>
units<<
الوحدات...
>>
example<<
مثال محلول...
>>
common_mistakes<<
الأخطاء الشائعة...
>>

حقول كل قانون الإلزامية: id, subject, category, title, equation, explanation,
symbols, units, example, common_mistakes.
كل رمز في symbols يكتب في سطر منفصل بالشكل: الرمز | المعنى | الوحدة.
لا تستخدم نفس id لقانونين.

تنبيه المحتوى:
ملف DEMO-PHYSICS.txt مثال توضيحي لطريقة عمل المكتبة فقط، وليس مصدرًا رسميًا لمنهج دراسي. احذفه عند بدء إدخال المحتوى الرسمي المراجع.

حدود الإصدار الحالي:
- الواجهة، المكتبة المعتمدة على TXT، البحث، المفضلة المحلية، مؤقت التركيز، آلة حسابية أساسية، نموذج معمل ثلاثي الأبعاد، قاموس الرموز، إعدادات المظهر واللغة الأساسية موجودة.
- المحاكاة الحالية نموذج بصري توضيحي وليست محاكاة علمية معتمدة. يلزم بناء نموذج مستقل والتحقق من معادلاته لكل تجربة متخصصة.
- الاختبارات، الحسابات والمزامنة السحابية، الترجمة الكاملة للغات الخمس، الحسابات وتعدد الأجهزة، والتخزين الخلفي تحتاج مراحل تطوير لاحقة وخدمات موثوقة.
- لا توجد قوانين منهجية رسمية مضافة في هذا الإصدار؛ لا تعتمد على ملف المثال في الدراسة.
